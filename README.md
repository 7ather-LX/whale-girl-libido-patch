# 鲸鲸生理状态补丁 · WhaleGirl Libido Patch

> **18+ 成人向状态模拟。** 只给成年人自己的私聊/角色扮演使用。
> 不涉及未成年、非自愿、暴力或违法内容。

把 **0–100 的性欲值、五档状态、每月发情期、72 小时曲线、事件记录** 接进鲸鲸，
并把当前状态注入鲸鲸的人设提示词，让聊天助手的语气和主动性随状态变化。

> 灵感来源：[amtoki520/dsh-libido-panel](https://github.com/amtoki520/dsh-libido-panel)
> （原项目是 DSH 的客户端面板；鲸鲸没有 DSH/Cordis 运行时，本补丁是独立重写，
> 不包含原项目代码，也不修改鲸鲸业务源码。）
>
> 本补丁：**7ather-LX** · **AGPL-3.0-only**。

## 它做什么

- **数值**：0–100；初始 18。
- **五档**：平静 / 有点想 / 难耐 / 快撑不住 / 发情。
- **时间**：醒着每 2 小时 +1；跨夜睡一觉砍半，不低于 10。
- **发情期**：每月 **18–20 日**；涨速翻倍，档位门槛整体降低 15。
- **事件**：摸尾巴 +8、被叫小母鱼 +5、被夸 +3、看了不该看的 +6、
  挨得近 +10、真的开始 +15 起、被凶/难过 −20；解决归 10。
- **曲线**：近 72 小时，每 30 分钟采样。
- **近况**：心情 / 陪伴 / 备注，写入状态文件。
- **提示词注入**：只注入语气和主动性，不会让模型播报数值；
  默认只私聊注入，群聊需手动打开。

## 面板与启动器

- 浏览器面板：<http://127.0.0.1:8787/libido-patch/>；
- **启动器左侧「生理」栏** 也打开同一个页面；
- 安装器会同时恢复 **补丁 / 图片 / 生理** 三栏，避免升级后旧两栏消失。

## 安装

先装 **鲸鲸 / Whale Girl 4.2.0**，然后：

1. 下载 ZIP 解压；
2. 双击 `install.cmd`；
3. 完全退出鲸鲸（托盘右键退出），重新打开；
4. 左侧应看到「补丁」「图片」「生理」。

安装器会：

- 把 `patch/` 复制到鲸鲸目录下的 `whale-libido-patch/`；
- 在 `server.js` 第一行插入 `require('./whale-libido-patch').install();`；
- 安装 **补丁 / 图片 / 生理** 三栏启动器（备份原 `WhaleLauncher.exe`）；
- 不动 `src/`、`config.json`；
- 创建桌面「管理页」快捷方式（可选）。

> 如果基础软件不是 4.2.0，仍可尝试，但只保证 4.2.0。

- 72 小时曲线；
- 事件按钮和自定义增减；

- 启用、注入、群聊注入开关。

## 配置

`data/whale-libido-config.json`：

```json
{
  "enabled": true,
  "inject": true,
  "injectGroups": false,
  "adult": true,
  "baseline": 12,
  "events": [
    { "id": "tail", "label": "摸尾巴 / 尾鳍", "delta": 8 }
  ]
}
```

- `injectGroups` 默认 `false`：只私聊注入，避免在群里出现成人向语气；
- 想群聊也生效，在面板勾选即可；
- 状态文件：`data/whale-libido.json`。

## 和原 DSH 插件的区别

| | DSH 原插件 | 本补丁 |
|---|---|---|
| 运行位置 | DSH 客户端（Cordis 插件 + 41888 面板） | 鲸鲸 Node 进程内的运行时补丁 |
| 显示 | DSH 输入框上方状态条 | 鲸鲸浏览器面板 `/libido-patch/` |
| 数据 | `~/.dsh/.../发情状态.json` | 鲸鲸 `data/whale-libido.json` |
| 提示词 | 原插件只显示，不注入 | **注入鲸鲸人设** |
| 代码 | 原项目 | 独立实现，未复制 |

鲸鲸不是 DSH，不能直接加载 DSH 的 `plugin/` 客户端模块；所以这里做的是**功能复刻**，
不是把原插件原样塞进去。

## 已知限制

- 状态是本地数值模拟，不是医学/心理诊断；
- 发情期固定按 **UTC+8** 的每月 18–20 日；
- 注入会多占一点提示词 token；
- 如果基础软件升级改了 `Store.buildContext` / `createRuntime` / `createRouter`，
  可能需要适配；
- **不要用于未成年人角色**；请自行确认聊天对象是成年人。

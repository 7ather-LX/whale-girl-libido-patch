# v1.0.0 · 生理状态接入鲸鲸

> **18+ 成人向状态模拟。** 只给成年人自己的私聊/角色扮演使用。

## 新增

- 0–100 性欲值；五档：平静 / 有点想 / 难耐 / 快撑不住 / 发情；
- 醒着每 2 小时 +1，跨夜睡一觉砍半（不低于 10）；
- 每月 18–20 日发情期：涨速翻倍、档位门槛降低 15；
- 72 小时曲线、事件记录、近况（心情 / 陪伴 / 备注）；
- 面板：<http://127.0.0.1:8787/libido-patch/>；
- 状态注入鲸鲸人设提示词，影响语气和主动性；
- 默认只私聊注入，群聊需手动打开。

## 和原插件的关系

灵感来源：<https://github.com/amtoki520/dsh-libido-panel>

原项目是 **DSH 客户端插件**（Cordis + 41888 面板），鲸鲸没有 DSH 运行时，
不能直接加载它的 `plugin/`。本补丁是鲸鲸运行时里的独立重写：

- 不复制原项目代码；
- 保留功能层面的状态规则、档位、发情期、事件、曲线和近况；
- 额外做了 **人设提示词注入**（原插件只显示数值）。

## 安装

1. 先装鲸鲸 4.1.2；
2. 下载 ZIP 解压，双击 `install.cmd`；
3. 完全退出鲸鲸再打开；
4. 打开面板，或直接私聊测试。

## 安全

- 状态只在本机 `data/whale-libido.json`；
- 面板只允许本机访问；
- 不涉及未成年、非自愿、暴力或违法内容；
- 数值不是医学/心理诊断。

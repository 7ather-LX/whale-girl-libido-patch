# v1.0.1 · 三栏启动器：补丁 / 图片 / 生理

> **18+ 成人向状态模拟。** 只给成年人自己的私聊/角色扮演使用。

## 修复

- 基础软件升级后，启动器换回了上游 4.1.2 版本：
  - 原来的「补丁 / 图片」两栏消失；
  - 「生理」没有入口。
- v1.0.1 附带一个 **多文件、框架依赖** 的 4.1.2 启动器：
  - 导航最上面依次是 **状态 / 补丁 / 图片 / 生理**；
  - 补丁页打开 `/patch/`；
  - 图片页打开 `/image-patch/`；
  - 生理页打开 `/libido-patch/`。
- 安装器同时安装这个启动器，备份原 exe，不再出现“装完补丁但启动器没入口”。

## 安装

1. 完全退出鲸鲸（托盘右键退出）；
2. 双击 `install.cmd`；
3. 重新打开鲸鲸；
4. 左侧应能看到「补丁」「图片」「生理」。

如果启动器仍显示旧界面，说明旧进程没退干净：托盘右键退出后，任务管理器确认没有 `WhaleLauncher.exe`，再打开。

## 说明

- 启动器是上游 4.1.2 的改动版，多文件构建，Defender 扫描无威胁；
- 三个页面都是本地 `127.0.0.1` 页面，没有外部网址；
- 补丁 / 图片页面没装对应补丁时会显示未连接，这是正常的；
- 生理页面只允许本机访问。
